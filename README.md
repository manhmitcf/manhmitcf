### ⚡ Key Repositories

- 👁️ [**DAT_Lab_Management**](https://github.com/manhmitcf/DAT_Lab_Management)  
  Edge AI video analytics on **NVIDIA Jetson Nano** (`DeepStream SDK` + `YOLOX` + `C++ OC-SORT` + `FP16 TensorRT`) paired with a real-time `Django Channels` WebSocket backend.

- 🤖 [**rag_chatbot_hasaki**](https://github.com/manhmitcf/rag_chatbot_hasaki)  
  Production-style RAG pipeline for 7k+ products: metadata chunking in `Qdrant`, two-stage retrieval with `BGE-Reranker`, deployed via `FastAPI` + `Docker`.

- 📑 [**Multimodal_Custom_Models_2026**](https://github.com/manhmitcf/Multimodal_Custom_Models_2026)  
  Layout-aware document extraction combining spatial bounding boxes with multimodal LLM visual reasoning.

- 🐟 [**fish_classification**](https://github.com/manhmitcf/fish_classification) & [**SLP_ML_Fish_Feeding_Audio**](https://github.com/manhmitcf/SLP_ML_Fish_Feeding_Intensity_Using_Audio)  
  Feature fusion & benchmark codebases supporting 2 Elsevier Scopus Q1 papers.
